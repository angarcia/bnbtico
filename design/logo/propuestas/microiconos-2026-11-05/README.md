# Opciones mínimas · propuestas pendientes de elección

Ana pide conservar la B fina como candidata, ensayar una B más ancha y comparar la opción de dejar solo el cuadrado al reducir. La falta de lectura a 16 px requiere una adaptación de proporciones y elementos, además de una exportación nítida.

1. `01-b-original`: B aprobada, con el mismo ajuste de grosor de la prueba anterior.
2. `02-b-mas-ancha`: esa misma B, ensanchada al 180 % respecto a su proporción original y con igual altura. Se reutiliza el mismo trazado; no se sustituye por otra fuente.
3. `03-b-negativo`: misma B ancha dentro de un cuadrado relleno.
4. `04-bt-compacta`: redibujo óptico de BT para dejar más superficie a las letras. Es una alternativa nueva y no cambia el nombre completo.
5. `05-cuadrado-solo`: cuadrado sin letras, reducido a ocho puntos grandes, dibujados a tamaño nativo.
6. `06-cuatro-esquinas`: cuadrado sugerido por cuatro esquinas gruesas; permite comparar una simplificación sin puntos. Puede recordar al símbolo de ampliar pantalla.

`comparativa.png` conserva la opción 1 como referencia y muestra 16/24/32/48 px. Cada opción incluye SVG y PNG de 16/24/32/48/64/128/512 px, además de crema sobre negro y variantes con fondo exterior transparente. Los iconos rellenos mantienen el cuadrado como parte del símbolo.

El logo completo mantiene las letras y las cuatro composiciones aprobadas. Estas opciones no están aplicadas a la app. Generador: `../../maestro/probar-microiconos.cjs` (Node y sharp).
