# Crema sobre negro · exportaciones de 4096 px

Cuatro composiciones renderizadas directamente desde los SVG: no se han ampliado las comparativas ni los PNG de redes. Se conserva crema #FFFBF2 sobre negro #000000, sin sombras, desenfoques, opacidades ni degradados.

Los PNG tienen 4096 px de ancho; las composiciones con marco son de 4096 × 4096. `detalle-puntos-sin-ampliar.png` es un recorte a escala 1:1 de esa exportación, sin ampliación posterior.

Para ampliar libremente o imprimir, usar los SVG de `../../unificado-2026-11-05/`. La comparativa original es un PNG de 1200 × 1020 y cada marco ocupa unos 430 px: ampliar esa comparativa amplía sus píxeles. El suavizado de un píxel en el borde de un círculo es antialiasing normal, no una sombra. A tamaños de icono se debe usar la variante simplificada preparada para ese tamaño.

Generador: `../../maestro/exportar-alta-resolucion.cjs`, desde la raíz del repo con Node y sharp disponibles.
