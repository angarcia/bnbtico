# bnbtico · juego de logos vectoriales

> **Entrega intermedia / compatibilidad.** Para materiales nuevos use [la biblioteca completa vigente](../biblioteca-completa-2026-11-05/LEAME.md). Esta carpeta se conserva por sus referencias y su procedencia; las notas siguientes describen aquella entrega.

2026-11-05 · Letras aprobadas, solo T elevada, sin rana. M de la imagen aportada por Ana. Cuatro composiciones: `bnbtico-*`, `bnbtico-com-*`, `bnbtico-cuadrado-*` y `bnbtico-com-cuadrado-*`. Cada composición tiene el mismo juego de colores y fondos.

Cada versión incluye SVG trazado y PNG. No requiere instalar fuentes. PNG horizontales: 2400 px de ancho; Instagram: 1254 × 1254; merchandising: 3000 × 3000. Los SVG son la fuente para escalar o preparar impresión; el proveedor debe ajustar tintas y tamaños al soporte final.

## Qué archivo elegir

| Sufijo | Uso |
| --- | --- |
| `terracota-transparente` | Web y maquetación sobre fondos claros. |
| `terracota-blanco` | Fondo blanco plano incluido. |
| `terracota-arena` | Fondo crema habitual #FFFBF2 plano incluido; «arena» es un alias compatible. |
| `terracota-crema` | Fondo crema #FFFBF2 plano incluido. |
| `blanco-transparente` | Fotografías: usar sobre una zona con contraste. Para fondos oscuros sólidos, elegir crema. |
| `crema-sobre-terracota` | Alternativa crema #FFFBF2 sobre terracota #B44C30 para fondos oscuros. |
| `crema-transparente` | Fondos oscuros o verde selva. |
| `crema-sobre-negro` / `crema-sobre-oscuro` / `crema-sobre-verde` | Composición con fondo plano incluido. |
| `sobre-fotos` | Logo blanco con fondo transparente, sin cartela ni rectángulo. Elegir una zona con contraste; para fotos claras también existe terracota transparente. |
| `negro-transparente` | Impresión monocroma. |
| `instagram-puntos` | Nombre dentro del marco doble de puntos, sobre crema plana. |
| `merchandising-puntos-negro` | Marco y nombre en negro, transparente, sin rana. |

Terracota #B44C30; no usar filtros CSS para recolorear los PNG. Mantener proporciones y dejar aire alrededor. El nombre completo no es la opción recomendada para 16–32 px: comparar las ocho opciones de `../propuestas/iconos-compactos-2026-11-05/` antes de decidir.

`comparativa.png` muestra fondos y alternativas. `referencia-vs-vector.png` permite comparar letras. `verificacion.json` documenta las comprobaciones. Las ocho alternativas compactas están pendientes de elección; no se han aplicado al favicon de la app.

`cuatro-versiones.png` reúne las cuatro composiciones. «Arena», beige y crema significan aquí el mismo fondo #FFFBF2, según la aclaración de Ana. La opción E es solo el cuadrado vacío de puntos: doble marco grande y simplificado a 16–32 px.

Todas las versiones con puntos usan círculos geométricos uniformes, con la posición del marco aprobado. Las nuevas opciones F/G/H añaden BT dentro de un cuadrado de 12/20/28 puntos; ver `../propuestas/iconos-compactos-2026-11-05/comparativa-bt-puntos.png`.

`cuatro-versiones-negro.png` y `cuatro-versiones-fotos.png` muestran las cuatro composiciones sobre negro puro y fotografías. Paquete específico en `../negro-y-fotos-2026-11-05/`.

Ajuste aprobado por Ana: en las cuatro composiciones, la tinta sobre negro y cualquier otro fondo oscuro sólido es crema #FFFBF2; sobre fotografías se conserva blanco #FFFFFF con transparencia. Las anteriores composiciones con blanco sobre oscuro sólido se conservan en el histórico, fuera del paquete vigente.
