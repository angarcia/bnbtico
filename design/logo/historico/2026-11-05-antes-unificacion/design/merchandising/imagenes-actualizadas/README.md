# Imágenes para merchandising

Selección del 2026-11-04: letras finas e irregulares del logo personalizado, sin los últimos cortes, aberturas ni remates descartados por Ana.

- `bnbtico-com-marco-puntos-negro.png`: diseño negro con marco doble de puntos y BNBTICO.COM; fondo transparente.
- `bnbtico-com-marco-puntos-vista-blanca.png`: vista sobre blanco para comprobar el diseño; usar el archivo transparente para subir a la imprenta si se quiere que se vea el tejido.
- Las otras cuatro imágenes contienen los logos con y sin dominio y con y sin rana. La versión BNBTICO con rana tiene fondo crema; las otras se generaron con transparencia.

Estos PNG son propuestas raster. La resolución y el grosor mínimo deben comprobarse al tamaño final de estampación con el proveedor. Las variantes generadas pueden presentar pequeñas diferencias de contorno.
