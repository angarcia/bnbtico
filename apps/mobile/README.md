# apps/mobile — Expo / React Native

Pendiente de scaffold. Responsabilidades:
- Cliente: explorar, pedir casa, favoritos, cuenta. Owner: panel, mis casas, calendario, contactos/solicitudes.
- Notificaciones push (nuevo contacto, nueva solicitud, casa aprobada, un owner te escribió).
- Deep links `wa.me`; subida de fotos y documentos de verificación con la cámara.
- La suscripción se paga en la web: aquí solo un enlace (evitar compras in-app).

Stack: Expo, expo-router, TypeScript, `@casatica/ui`, `@casatica/api-client`.
