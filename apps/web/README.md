# apps/web — Next.js

Pendiente de scaffold. Responsabilidades:
- Landing pública (`/`), catálogo (`/casas`), fichas SSR indexables (`/c/CT-1042-villa-brisa-tamarindo`).
- Flujos de cliente, owner y admin (mismas pantallas que `docs/design.md`).
- **Checkout de suscripción** (tarjeta recurrente + SINPE Móvil): solo aquí, no en la app móvil.
- Sitemap por provincia/destino y Open Graph con foto de portada.

Stack: Next.js App Router, TypeScript, `@casatica/ui`, `@casatica/api-client`, Supabase SSR.
